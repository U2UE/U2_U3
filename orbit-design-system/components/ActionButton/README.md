# ActionButton

Orbit의 유일한 버튼: 투명 바탕, 1px `line-2` 외곽선, `radius-5`, 12px `ink-2`.

- hover에 외곽선 `accent`, 글자 `accent-ink`. 비활성은 `opacity-disabled`.
- 크기는 하나(3px 10px). 헤더 안·카드 안에서는 1px 8px, 11px로 줄인다.
- 채운(primary) 버튼이 없다 — 강조가 필요하면 문구로 한다. 삭제는 같은 버튼에 글자만 `bad`.
- `<a class="act">`로 외부 링크(Sheet)에도 쓴다.

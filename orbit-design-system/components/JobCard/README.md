# JobCard

이직 지원 한 건(가로 레일 카드).

- 스트라이프 `--pc`와 단계 배지 `.stg`(10px 700, `surface` 글자)가 같은 단계 색(`stage-*`, 결과면 `result-*`).
- 머리줄 오른쪽 `.due`: mono 10px, 5일 이하면 `.dead`(bad). 회사명 13px 600, 포지션 12px `ink-2`.
- 단계 막대 `.pipe`(중립). 아래줄 「다음: …」 + 이전 `‹` · 다음 단계 `면접 ›` · 편집.
- 접근성: 몇 단계 색은 배지 글자 대비가 미달이다(README 접근성 메모).

# BriefTile

브리핑 줄의 한 칸: 왼쪽에 키와 한 줄 설명, 오른쪽에 큰 값.

- 구조: `.bt` 안에 `.k`(label, `ink-3`), `.s`(12px `ink-2`), `.v`(`tile-value`). 값 뒤 단위는 `<small>`.
- 톤 클래스로 왼쪽 3px 바와 값 색이 바뀐다: 기본 `line-2`, `.ok` accent, `.warn` amber(대기·등록 필요), `.bad` 마감(면 전체가 `bad-soft`).
- `.now` 변형은 아래에 「완료」「넘김」 버튼 줄(`.now-act`)이 붙는다. 우선순위: 타인 대기 제외 → 마감 오름차순 → 외주 > 커리어 > 공부.
- 줄은 4칸 고정(860px 이하 2칸). 칸을 추가하지 않는다.

# ClockHeader

페이지 맨 위 한 줄: 왼쪽 날짜, 오른쪽 해·달 아이콘과 시각.

- 날짜와 시각은 같은 스타일 `clock`(19px 700, 행간 1). 날짜만 18px로 1px 줄여 한글과 숫자의 높이를 맞춘다. 요일은 `<small>` 12px 500 `ink-3`.
- 아이콘은 06–18시 해(`clock-day`), 그 외 달(`clock-night`), 18px.
- 소비자가 줄 것: 날짜 문자열, 요일, HH:MM(Asia/Seoul, 24시간).
- 하지 말 것: 인사말·날씨·큰 히어로를 붙이지 않는다.

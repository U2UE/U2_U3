# Segmented

붙어 있는 칸으로 된 선택기. 두 용도가 있다.

- **단계 파이프(`.gpipe`)**: 진행 → 납품 → 정산 대기 → 정산 완료. 지난 칸 `ink-2`, 현재 칸 `ink-3` 채움 + `surface` 글자 600, 앞 칸은 `ink-3`. 단계는 상태가 아니므로 신호색을 쓰지 않는다.
- **보기 전환(`.gview`, `.stf .seg`)**: 「할 일 | 금액」. 선택은 `surface-2` + `ink` 600. 칸 안의 작은 amber 숫자(`<i>`)는 시트에 옮기지 않은 변경 수.
- 외곽 1px `line-2`, `radius-5`, 칸 사이 1px `line`.

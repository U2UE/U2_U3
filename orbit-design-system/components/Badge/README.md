# Badge

글 옆에 붙는 작은 사각 라벨(10–11px, `radius-3`).

- 마감 `.pill`: `bad-soft`/`bad` — 일정 제목 옆 「마감」.
- 계정 `.acct`: 기본 ljh = `warn-soft`/`warn`, `.acct.u` uzuelee = `accent-soft`/`accent-ink`.
- 대기 `.gwait`: 「대기 · 검수문안 미수령」 — 클라이언트에게 받을 것이 있을 때만.
- 묶음 `.gch`: 중립 `ring-line-inset` — 금액 행의 「생헌」「헌생」.
- 배지는 한 줄에 하나 또는 둘. 색은 「색 역할」 표를 따른다.

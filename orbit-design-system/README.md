Orbit은 한 사람의 하루를 한 화면에 모으는 개인 대시보드다. 마감·지금 할 일·메일·공부를 위에서 한눈에 보고, 아래에서 일정·메일·파일·트래커를 조작한다. 어두운 바닥 위에 조용한 청록 하나, 그리고 역할이 고정된 신호색 몇 개로 움직인다.

## 원칙

- **다크 단일 테마.** Orbit은 라이트 테마를 두지 않는다(v32에서 제약 삭제). 새 화면도 `bg` 바닥, `surface` 패널로 시작한다.
- **요약이 먼저, 상세는 아래.** 맨 위 브리핑 4칸(DEADLINE · NOW · INBOX · STUDY)이 페이지의 결론이고, 패널은 그 근거다. 브리핑 타일은 2행(키 / 한 줄 설명) + 우측 값 하나로 고정, 높이 84px. 3행·버튼 행 금지. 값 슬롯에는 숫자·라틴만 넣는다.
- **색은 역할이다.** 색을 꾸밈으로 쓰지 않는다. 아래 「색 역할」에 없는 곳에 신호색을 칠하지 않는다.
- **조용함이 기본값이다.** 강조 수단은 크기 위계(32 > 22 > 14) 하나뿐이다. 색은 상태가 있을 때만 켜지고, 상시 켜진 신호색은 오류다. 그라데이션·글로우·그림자·장식 아이콘·애니메이션을 추가하지 않는다(허용된 모션은 LIVE 맥박과 진행바 폭뿐).
- **밀도는 높게, 소음은 낮게.** 메타 정보(소유자·용량·절대시간·마지막 갱신)는 `title` 툴팁으로 보내고 행에는 이름과 상대시간만 남긴다.

## 콘텐츠

- 화면 문구는 한국어. 영문은 전부 대문자다 — 타일 키 DEADLINE · NOW · INBOX · STUDY, 패널 제목 SCHEDULE · INBOX · FILES, 탭 STUDY · CAREER · CLIENT, 칩 LIVE, 버튼 SHEET. 한글엔 대문자 변환·자간을 적용하지 않는다.
- 버튼은 짧은 동사·명사: 「완료」「넘김」「편집」「접기」「폴더」「SHEET」. 추가 버튼은 `+ 외주 추가`, `+ 강의 추가`, `+ 금액 변경 기록`처럼 `+ ` 로 시작한다.
- 기술 용어를 쓰지 않는다. "db 저장" 대신 「저장됨」, "API 오류" 대신 「연결이 만료됐습니다. claude.ai 설정 → 커넥터에서 Gmail을 다시 연결하세요.」처럼 고치는 방법까지 쓴다.
- 시간은 상대시간(「1분 전」「6시간 전」「2일 전」), 날짜는 「9월 25일 금요일」, 마감은 `D-1`·`D-DAY`·「지남」. 금액은 쉼표 원 단위 숫자(`1,748,336`), 변경은 부호(`+51,000`).
- 개수는 라벨 옆 작은 mono 숫자로 붙인다(「전체 11」「Study 11」). 괄호로 감싸지 않는다.
- 이모지를 쓰지 않는다. 구분자는 가운뎃점 ` · `.

## 색 역할 (260924 확정)

| 역할 | 토큰 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|---|
| 브랜드·살아있음·현재 | `accent`, `accent-soft`, `accent-ink` | LIVE 칩, 안 읽은 메일 점, 선택된 탭, 현재 강의 카드 테두리, 모든 진행바(공부·외주), 포커스 링, 오늘 | 경고·마감 |
| 마감 | `bad`, `bad-soft` | Deadline 타일, D-day 배지, 임박 due(5일 이하), 음수 금액, 삭제 | 대기·방치 (amber를 쓴다) |
| 타인 대기·방치·주의 | `warn`, `warn-soft` | 「대기 · 검수문안 미수령」, 자료 대기 상태, stale, 방치된 강의, 시트 미반영 변경 | 마감 |
| 진행 중·커리어 | `info`, `info-soft` | 작업 「진행」 상태, Career 탭 | |
| 외주 | `gig` | Client 탭 점, 패널 윗선 | 진행바·단계 버튼·금액 수치 — 진행바는 `accent`, 남은 돈은 `ink` 700 |
| 샘플 데이터 | `sample`, `sample-soft` | 가데이터 패널 하단 문구 | 실제 데이터 |
| 단계 흐름 | `ink-3`, `line` (중립) | 이직 파이프, 외주 단계 세그먼트의 현재 칸 | 신호색 금지 — 단계는 상태가 아니다 |

- 패널 종류는 상단 2px 선(`accent` / `info` / `gig`)과 탭 앞 6px 점으로만 구분한다.
- 계정 배지는 둘 다 중립(`ring-line-inset`, 글자 `ink-2`). 계정 식별에 신호색을 쓰지 않는다.
- 강의 플랫폼(`platform-*`)과 이직 단계(`stage-*`, `result-*`)는 카드 좌측 3px 스트라이프와 단계 배지에만 쓴다. 다른 요소에 번지지 않는다.

## 타이포그래피

- 본문은 `IBM Plex Sans KR`(font-sans), 숫자·시각·금액·코드는 `IBM Plex Mono`(font-mono). 둘 다 Google Fonts에서 불러온다.
- 기본은 `body`(14px/1.5). 패널 제목 `panel-title`, 메타는 `meta`, 라벨은 `label`. 크기 위계는 세 단뿐이다: `tile-value`(32px) > `clock`(22px) > `panel-title`(14px). 타일 값이 항상 화면에서 가장 크다. 값 옆 단위(건·일·/ 10통)는 `tile-unit`으로 baseline 정렬, 간격 6px.
- 줄을 맞춰 읽는 숫자(시각, 금액, 개수)에는 항상 `font-variant-numeric: tabular-nums`.
- 영문 자간: 11px 라벨 .08em, 14px 패널 제목 .04em, 13px 탭 .04em. 32px 값에는 영단어를 넣지 않는다(대문자 단어가 숫자 옆에서 과도하게 무겁다).
- 넘치는 텍스트는 한 줄 말줄임(ellipsis)이 기본이다. 행은 줄바꿈으로 높이가 변하지 않는다.

## 간격과 레이아웃

- 페이지 폭 `layout-max` 1180px, 좌우 `space-24`. 브리핑 4열 → 일정/파일 7 : 메일 5의 2단 그리드, `layout-breakpoint` 860px 이하에서 1열(브리핑은 2열).
- 패널 사이 `space-14`. 패널 안 모든 행과 헤더는 좌우 `space-16`에 정렬한다.
- 행은 `9px 16px` 패딩에 위쪽 1px `line` 구분선. 첫 행은 구분선이 없다. 행은 카드가 아니다 — 행에 모서리나 그림자를 주지 않는다.
- 가로로 넘치는 목록(강의·지원 카드)은 `card-width` 236px 카드의 가로 레일 + scroll-snap.

## 면, 테두리, 모서리

- 깊이는 그림자가 아니라 면의 단계로 만든다: `bg` → `surface`(패널) → `surface-2`(요약줄·카드·hover). 그림자 토큰은 1–2px 링뿐이다.
- 테두리는 1px. 장식 구분선은 `line`, 조작 가능한 것의 외곽선은 `line-2`. 샘플 패널은 점선(`line-2`).
- 모서리는 작고 일정하다: 컨테이너 `radius-6`, 버튼·입력 `radius-5`, 작은 배지 `radius-3`, 칩·탭·D-day는 `radius-pill`.

## 상태와 모션

- hover: 행은 배경 `surface-2`, 버튼은 테두리·글자가 `accent`/`accent-ink`로. 부차 버튼(−, 편집)은 카드 hover·focus 때만 보인다.
- 선택: 필터 탭은 `accent-soft` 채움 + `accent-ink` 600, 세그먼트는 `surface-2` 채움 + `ink` 600.
- 흐림으로 상태를 말한다: 취미 `opacity-hobby`, 완강 `opacity-done`, 정산 완료 `opacity-fin`.
- 포커스: `outline: 2px solid var(--accent); outline-offset: 2px`.
- 모션은 두 가지뿐: LIVE 점의 2.4s ease-in-out 맥박(불투명도 1 → .35), 진행바 폭 .4–.5s ease. `prefers-reduced-motion`에서 맥박을 끈다.

## 아이콘

- 아이콘 세트를 쓰지 않는다. 파일 종류는 34px 사각 안의 mono 약어(`DOC` `SHT` `SLD` `PDF` `IMG` `DIR` `AI` `PSD`)로 표시하고, 폴더는 `accent-soft`, AI·PSD는 `file-ai-soft`/`file-ai`.
- 선 아이콘은 헤더 시계의 해·달 두 개뿐이다: 24 viewBox, stroke 2, round cap, 낮 `clock-day` / 밤 `clock-night`. 새 아이콘이 필요하면 같은 규격의 선 아이콘으로 만든다.
- 상태 점은 6–7px 원(LIVE, 안 읽음, 탭 종류).

## 접근성 메모 (원본 값 유지, 표시만)

- `ink-3`은 v33에서 `#8A969C`로 상향(surface 5.43:1, surface-2 4.81:1). 단계 배지 대비 미달은 Career 탭 한정으로 보류.
- 단계 배지(`surface` 글자 on 단계 색): `stage-applied` 3.01, `stage-docs` 2.91, `result-fail` 2.42, `result-hold` 3.26으로 미달.
- 컨트롤 외곽선 `line-2`는 `surface` 대비 1.67:1로 3:1 미달. 버튼은 글자(`ink-2`, 8.15:1)로 식별된다.
